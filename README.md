# Geometry of Spectral Evolution

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)]()

------
This package implements methods to treat the empirical spectral density (ESD) of a normalized graph Laplacian as a point in Wasserstein space, and a temporal graph as a curve in this space. It also implements geometric descriptors to analyze the geometry of graph spectral evolution over time.
